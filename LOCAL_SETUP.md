# EvaWarm local setup

Open the terminal in this folder (`evawarm_work`).

## Install
```powershell
npm install
```

## Website
```powershell
npm run dev
```
Open http://localhost:8443/

## Decap CMS
Open a second terminal in the same `evawarm_work` folder:
```powershell
npm run cms
```
Then open http://localhost:8443/admin/

Keep both terminals running during local CMS testing.
